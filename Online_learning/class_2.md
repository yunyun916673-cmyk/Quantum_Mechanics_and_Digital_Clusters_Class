# 第二堂：連續性與微分的進一步理解

## 一、這堂課學到的內容

這堂課主要是透過題目的練習，進一步認識微積分中的一些基本概念。

這堂課讓我印象比較深刻的內容包括：

連續性的基本概念
極限與函數值之間的關係
連續但不可微分的函數
絕對值函數的尖角
微分與局部線性近似
利用內接與外切正 n 邊形逼近圓
利用夾擠定理證明圓的面積公式

## 二、連續性的基本概念

如果一個函數在 x = A 的地方連續，基本上需要滿足：

lim(x→A) f(x) = f(A)

也就是說，當 x 越來越接近 A 時，f(x) 的值也會越來越接近 f(A)。

這裡其實包含幾個條件：

f(A) 必須存在

lim(x→A) f(x) 必須存在

而且兩者必須相等。

因此，如果函數在某個地方有「洞」、突然跳躍，或是函數在該點的數值與附近趨近的結果不同，就會變成不連續。

## 三、不連續不代表沒有極限

這堂課讓我注意到一個很重要的觀念：

不連續不代表沒有極限。

例如：

f(x) = x²，x ≠ 2

在 x = 2 的地方，函數沒有定義，因此圖形在那裡會出現一個洞。

但是：

lim(x→2) f(x) = 4

仍然存在。

也就是說，雖然 f(2) 不存在，但是當 x 越來越接近 2 時，f(x) 仍然會越來越接近 4。

另一種情況是：

f(x) =
x²，x ≠ 2
9，x = 2

這時：

lim(x→2) f(x) = 4

但是：

f(2) = 9

所以：

lim(x→2) f(x) ≠ f(2)

因此函數仍然不連續。

這讓我理解到，判斷連續性時，不只是看函數有沒有定義，而是要比較「附近逼近的結果」與「函數在該點的值」。

## 四、連續但不可微分

這堂課另一個讓我印象很深的例子是：

y = |x|

它的圖形是一個 V 字形。

可以寫成：

f(x) =
x，x ≥ 0
-x，x < 0

這個函數在 x = 0 的地方其實是連續的。

但是它在 x = 0 的地方無法微分。

原因是微分可以理解成研究函數在某一點附近的瞬間變化率，也可以從切線的斜率來理解。

對 y = |x| 而言：

從左邊接近原點時，斜率是 -1。

從右邊接近原點時，斜率是 1。

因此：

左導數 = -1

右導數 = 1

左右兩邊不相等，所以在原點不存在唯一的導數。

## 五、我對「可微分」的進一步理解

我目前對微分的理解是：

如果把函數圖形放大到某一個點附近非常小的範圍，函數可以越來越接近一條直線，那麼就可以利用這條直線來描述函數在這個點附近的局部變化。

例如：

y = x²

雖然整體來看是一條曲線，但是在某一個點附近，如果觀察的範圍足夠小，就可以用切線來近似它。

因此我認為：

微分可以理解成研究函數的「局部變化」。

但是 y = |x| 在原點比較特殊。

因為從左邊放大時，得到的局部斜率是 -1；從右邊放大時，得到的局部斜率是 1。

也就是說，它沒有辦法在原點找到一個唯一的局部線性近似。

因此：

連續不一定代表可微分。

y = |x| 就是一個很典型的例子。

## 六、利用內接與外切正 n 邊形求圓的面積

這堂課另外一個讓我覺得很有趣的內容，是利用極限與夾擠定理證明圓的面積。

目標是證明：

圓的面積 = πr²

可以先在半徑為 r 的圓內畫一個正 n 邊形。

因為正 n 邊形完全位於圓的內部，所以：

內接正 n 邊形的面積 < 圓的面積

接著在圓外畫一個正 n 邊形，使圓內切於這個正 n 邊形。

此時：

圓的面積 < 外切正 n 邊形的面積

因此可以得到：

內接正 n 邊形面積
≤ 圓的面積
≤ 外切正 n 邊形面積

## 七、利用夾擠定理得到圓的面積

接著讓 n 不斷增加。

當 n 越來越大時，正 n 邊形的邊會越來越短。

內接正 n 邊形會越來越接近圓。

外切正 n 邊形也會越來越接近圓。

因此，當 n 趨近無限大時，內接正 n 邊形與外切正 n 邊形的面積都會趨近同一個值。

由夾擠定理，圓的面積也必須趨近這個值。

經過計算後，可以得到：

圓的面積 = πr²

這個證明讓我發現，原本看起來很直觀的圓面積公式，其實也可以透過極限與幾何逼近的方式嚴格地建立起來。

## 八、目前的理解

目前我對這堂課的理解是：

連續性主要是在研究函數在某一點附近的行為，以及附近逼近的結果是否與函數在該點的值一致。

不連續的函數仍然可能存在極限。

連續的函數也不一定可以微分。

y = |x| 在原點就是一個例子。它雖然連續，但是因為左右兩側的瞬間變化率不同，所以在原點不可微分。

微分可以從「局部線性近似」的角度理解。

另外，圓的面積公式也可以透過極限來證明。利用內接與外切正 n 邊形，可以把圓的面積夾在兩個近似值之間。

當 n 越來越大時，兩個近似值會越來越接近，因此可以利用夾擠定理得到真正的圓面積。

這讓我更加感受到「極限」的重要性：

有些結果不一定能直接得到，但可以透過不斷逼近，最後把它確定下來。
