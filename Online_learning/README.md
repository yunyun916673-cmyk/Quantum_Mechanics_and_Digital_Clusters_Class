# Online_Learning

本資料夾用於記錄「量子力學之美，數位叢集計算」課程中的線上自主學習內容。

課程提供相關的線上影片作為學習資源，學生可以依照自己的興趣與學習進度，自由選擇想觀看的影片，進一步了解課堂以外的相關概念與知識。

## Learning Method

線上學習主要採取自主學習的方式：

* 從老師提供的影片資源中選擇感興趣的主題。
* 觀看影片並理解其中介紹的概念。
* 將學習過程中接觸到的重要概念、問題與想法整理下來。
* 視需要進一步查找資料或延伸探索相關主題。

因此，這個資料夾並不是固定的課程進度，而是用來記錄個人在課程提供的資源中所進行的探索與學習。

## Contents

目前的內容將依照學習主題分類，並持續隨著課程進行更新。

每個主題可以包含：

* 影片或學習資源
* 影片內容摘要
* 學習到的概念
* 個人的理解與思考
* 延伸閱讀或進一步探索的內容

## Purpose

透過自主選擇與整理學習內容，希望能在課堂之外，建立對量子力學、數位叢集計算以及相關資訊科學概念更完整的理解，並記錄自己的學習歷程。
